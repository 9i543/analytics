🎯 如何使用

📁

資料夾結構

每個網頁放在獨立的資料夾中（web1、web2、web3），主頁在根目錄。

🚀

GitHub Pages

上傳到 GitHub 存儲庫，啟用 GitHub Pages 功能即可發佈。

⚡

擴展性

您可以輕鬆添加更多網頁（web4、web5...），只需遵循相同結構。

🎨

自定義

每個網頁都可以完全自定義設計，展示不同的創意和技術。
